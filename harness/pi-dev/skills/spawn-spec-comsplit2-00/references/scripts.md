# Скрипты

<!-- cspell:ignore коммита коммитер коммитит коммиты криптоподписи неотслеживаемые подсессии репо -->
<!-- markdownlint-disable-file MD013 -->

Действует на всех этапах.

Скрипты лежат в `SKILL_DIR/scripts/`, принимают абсолютные пути и заменяют ручные команды git. При ненулевом коде возврата прочитать сообщение на stderr и действовать по правилам этапа, не повторять команду вручную.

- `run-dir.sh <MAIN_DIR> <SPECS_REPO> <краткое-имя> [<тема>]` – создаёт каталог прогона и печатает `RUN_REL`.
- `worktree.sh <MAIN_DIR> <слог репо> <слог задачи>` – проверяет, что основная рабочая копия чистая и `HEAD` не отсоединён, создаёт от `HEAD` ветку и worktree по правилам этапа 1 и печатает три строки: ветку, `WT_DIR` и `HEAD`. При ненулевом коде возврата остановиться и спросить меня.
- `snapshot.sh <каталог>` – печатает хеш дерева: снимок рабочего дерева без коммитов и без изменения индекса, неотслеживаемые файлы входят, игнорируемые – нет.
- `review-bundle.sh <WT_DIR> <FROM> <TO> <OUT>` – пишет в `OUT` пакет для ревью между снимками `FROM` и `TO`: `git diff --stat` и `git diff -U10`.
- `spec-files.sh <каталог>` – печатает манифест каталога вложений или правок строками `<SHA256> <путь>`.
- `precedents.sh <SPECS_REPO> <владелец>/<репо> [<ключевое слово>…]` – прецеденты по `references/autonomy.md`: прогоны с `decisions.md` или `task.md` от новых к старым по дате из имени каталога, прогоны этого проекта помечены `*`; без ключевых слов печатает список прогонов, с ними – совпавшие строки этих файлов без учёта регистра.
- `commit-specs.sh <SPECS_REPO> <RUN_DIR>` – добавляет каталог прогона в индекс и коммитит только его: сообщение `add <RUN_REL> spec` для первого коммита каталога, `update <RUN_REL> spec` для остальных; без изменений ничего не коммитит и печатает `nothing to commit`.
- `commit-project.sh <WT_DIR> <сообщение> [<путь>…]` – единственный коммит в проект: без путей добавляет всё через `git add -A`, с путями – только их; печатает SHA и сообщение коммита.

Правила коммитов:

- коммитит только роль `оркестратор`: в проект – один итоговый коммит в `WT_DIR` на этапе 4, в репозиторий спек – после каждой подсессии роли, изменившей файлы в каталоге прогона, и в конце прогона;
- автор и коммитер – из раздела «Роли» `SKILL.md`, а не из `git config`; коммиты без криптоподписи; в коммит в репозиторий спек попадает только каталог прогона, чужие изменения там не трогать;
- добавлять `Co-Authored-By` и любые другие трейлеры с упоминанием моделей запрещено.
